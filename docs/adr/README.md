# docs/adr

Architecture Decision Records — one Markdown file per significant technical decision (e.g. Kafka over RabbitMQ, ConnectRPC). New ADRs follow the template added in SMM-16 and require principal-engineer (and human, for stack changes) sign-off.

See also [`docs/security/threat-model.md`](../security/threat-model.md) for the project's threat model and security posture, and [`SECURITY.md`](../../SECURITY.md) for the vulnerability reporting process.
